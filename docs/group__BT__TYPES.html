◆ bt_status_t

enum bt_status_t

Execution status returned by every node tick.

Leaf callbacks must return one of BT_SUCCESS, BT_FAILURE, or BT_RUNNING. BT_INVALID and BT_ERROR are set by the library, never by user code.

Enumerator
BT_SUCCESS 

Node completed its task successfully

BT_FAILURE 

Node completed but did not achieve its goal

BT_RUNNING 

Node is still executing (long-running operation)

BT_INVALID 

Node has not been ticked / was halted

BT_ERROR 

Internal error (NULL pointer, alloc failure, etc.)
