Create a leaf Action node.

Actions represent ongoing operations. Their tick_fn may return BT_RUNNING to signal work in progress; on the next tree tick tick_fn is called again (without calling on_init_fn again) until the action returns a terminal status.

Parameters
[in]nameHuman-readable label (stored by pointer; use a string literal). Ignored if BT_ENABLE_NODE_NAMES=0.
[in]tick_fnMandatory execution callback (must not be NULL).
[in]on_init_fnCalled at the start of each execution cycle. Pass NULL if not needed.
[in]on_halt_fnCalled when the node is forcibly interrupted. Pass NULL if not needed.
[in]user_dataAvailable through node->user_data in callbacks.
Returns
Pointer to new node, or NULL on allocation failure.

bt_node_t * bt_parallel_create ( const char *  name,
uint16_t  success_threshold 
)

Create a Parallel composite node.

Ticks all children on every tree tick (fully reactive). This makes it ideal for safety monitoring: combine conditions with long-running actions; if any condition fails the whole parallel fails and the actions are halted.

Parallel [threshold = N]
├── Condition A (re-evaluated every tick)
├── Condition B (re-evaluated every tick)
└── Action C (continues its RUNNING state across ticks)
Parameters
[in]nameHuman-readable label.
[in]success_thresholdNumber of children that must return BT_SUCCESS for the Parallel to return BT_SUCCESS. The node returns BT_FAILURE when (child_count - failures) < threshold, making success impossible.
Returns
Pointer to new node, or NULL on allocation failure.

int32_t  max_count

Create a Repeater decorator node.

Repeats the child node max_count times. The child is re-initialised (on_init is called) at the start of each repetition.

  • Returns BT_RUNNING while repeating.
  • Returns BT_SUCCESS after completing all repetitions.
  • Returns BT_FAILURE immediately if the child returns BT_FAILURE.
Parameters
[in]nameHuman-readable label.
[in]max_countNumber of repetitions. Pass -1 to repeat indefinitely (the node never returns BT_SUCCESS).
Returns
Pointer to new node, or NULL on allocation failure.

Create a Retry decorator node.

Retries the child node on BT_FAILURE up to max_retries times.

  • Returns BT_SUCCESS immediately when the child returns BT_SUCCESS.
  • Returns BT_RUNNING while retrying.
  • Returns BT_FAILURE after exhausting all retry attempts.

bt_node_t * bt_selector_create ( const char *  name)

Create a Selector (?) composite node.

Ticks children left-to-right (stateful/memory policy):

  • Returns BT_SUCCESS on the first child that returns BT_SUCCESS.
  • Returns BT_FAILURE if all children return BT_FAILURE.
  • Returns BT_RUNNING while a child is RUNNING; resumes from that child on the next tick.

[in]nameHuman-readable label.
