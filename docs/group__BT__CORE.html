Allocate and initialise a behaviour tree.

Parameters
[in]rootRoot node; must be fully constructed (children added) before this call.
[in]contextOpaque pointer forwarded unchanged to every tick / on_init / on_halt callback. May be NULL.
[in]thread_safeWhen true a recursive mutex is created and bt_tree_tick is safe to call concurrently from multiple RTOS tasks. When false no mutex overhead is incurred.
Returns
Pointer to the new tree, or NULL on allocation failure.
Note
Build the tree (nodes + children) before calling this. Construction helpers are not protected by the tree mutex.

◆ bt_tree_destroy()

void bt_tree_destroy ( bt_tree_t *  tree)

Halt and free the tree and every node it owns.

Calls bt_node_halt on the root (propagates to all RUNNING descendants), then recursively frees all nodes, then frees the tree itself. Destroys the mutex if one was created.

Parameters
[in]treeTree to destroy. May be NULL (no-op).
Warning
Do not call bt_tree_tick after this.

◆ bt_tree_tick()

bt_status_t bt_tree_tick ( bt_tree_t *  tree)

Execute one tick of the behaviour tree.

Acquires the tree mutex (if thread_safe), ticks the root node, updates statistics if enabled, releases the mutex, and returns the root status.

Call this at a fixed rate from your control loop or an RTOS task:

while (1) {
vTaskDelay(pdMS_TO_TICKS(20));
bt_tree_tick(tree);
}
