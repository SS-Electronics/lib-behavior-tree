Detailed Description

Single node in the behaviour tree.

Composite and decorator nodes own a heap-allocated array of child pointers that grows automatically. Leaf nodes have child_count == 0.

Note
Do not modify fields directly; use the factory and manipulation functions instead. Internal fields (initialized, running_child, repeat_count) are managed by the library.
