Forcibly interrupt a node and all of its running descendants.

Recursively calls bt_node_halt on every initialized child, then calls this node's on_halt_fn (if set), then resets initialized, status, running_child, and repeat_count.

This function is a no-op if node is NULL or node->initialized is false (the node is not currently mid-cycle).

Parameters
[in,out]nodeNode to halt.
[in]contextUser context pointer.

Forcibly interrupt a node and all of its running descendants.

Implementation notes:

  • The function is a no-op when node->initialized is false because a non-initialized node is not mid-cycle and needs no cleanup.
  • Recursion propagates halt to all initialized descendants first, then calls this node's on_halt_fn, matching the tear-down order that a user would expect (leaves first, then their parents).

void *  context 
)

Tick a single node.

Calls on_init_fn the first time a node is ticked in a new execution cycle (when initialized is false), then calls tick_fn. Resets the initialized flag when tick_fn returns a terminal status so on_init_fn is called again next cycle.

Parameters
[in,out]nodeNode to tick.
[in]contextUser context pointer.
Returns
Status returned by tick_fn, or BT_ERROR if node or tick_fn is NULL.

Tick a single node.

Execution cycle per node:

  1. If node->initialized is false: call on_init_fn (if set), set initialized = true.
  2. Call tick_fn and record the returned status.
  3. If the status is terminal (SUCCESS or FAILURE), set initialized = false so the next call restarts the cycle.
