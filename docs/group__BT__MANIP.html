bt_status_t bt_node_add_child ( bt_node_t *  parent,
bt_node_t *  child 
)

Append a child node to a composite or decorator node.

The children array grows automatically (doubles in capacity when full). Sets child->parent to parent.

Parameters
[in,out]parentNode to attach the child to.
[in]childNode to append.
Returns
BT_SUCCESS on success, BT_ERROR on allocation failure or NULL input.

Append a child node to a composite or decorator node.

Growth strategy: capacity doubles on each reallocation, starting from BT_CHILDREN_INITIAL_CAPACITY. The old array is freed after copying.

void bt_node_destroy ( bt_node_t *  node)

Recursively free a node and all of its descendants.

Frees the children array and the node struct for every node in the sub-tree. Does NOT call on_halt — halt the tree (or sub-tree) first if nodes may still be RUNNING.

Parameters
[in]nodeRoot of the sub-tree to free. May be NULL (no-op).
